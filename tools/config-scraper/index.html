Config Scraper

Automatically backup network device configurations with Git version control. Track every change, restore any version.

⬇️ Download for Windows 📂 View Source

Features

🔄 Auto Backup

Schedule automatic config backups at any interval. Never lose a config change again.

📊 Git Version Control

Every config change is committed to a local Git repo with timestamps and diffs.

🔐 Encrypted Credentials

Device passwords stored securely using Windows DPAPI encryption.

📋 Bulk Import

Add dozens of devices at once with shared credentials. Perfect for large deployments.

🌐 Web Interface

Clean, modern UI accessible from any browser on your network.

📈 Diff Viewer

Visual comparison of config changes with syntax highlighting.
